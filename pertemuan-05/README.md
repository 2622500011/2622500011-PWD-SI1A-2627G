# pertemuan-05
P5 - JavaScript Dasar, DOM, Event, dan Validasi Sisi Klien
Deskripsi

Dokumentasi pengembangan halaman web pada pertemuan 05 (P5), meliputi JavaScript dasar, DOM, event listener, interaksi navigasi, dan validasi formulir sisi klien. Pada tahap ini, halaman web diperiksa agar tetap sama seperti hasil P4 dan dilakukan penambahan fitur menggunakan JavaScript.

Fitur dan Pengembangan
Penyiapan Direktori dan Berkas: Menyiapkan direktori dan berkas yang dibutuhkan untuk pengembangan halaman web pada P5.
Pemeriksaan Halaman Web: Memeriksa tampilan halaman web agar tetap sama seperti P4.
JavaScript Dasar: Menambahkan JavaScript untuk membuat halaman web lebih interaktif.
DOM (Document Object Model): Menggunakan DOM untuk mengakses dan mengubah elemen pada halaman web.
Event Listener: Menambahkan event listener untuk menangani interaksi pengguna pada halaman web.
Interaksi Navigasi: Mengembangkan interaksi pada menu navigasi agar dapat digunakan dengan baik.
Validasi Formulir Sisi Klien: Menambahkan validasi formulir menggunakan JavaScript sebelum data dikirim.
